# דוחות בדיקה

אפליקציית WEB לכתיבת דוחות בדיקה לחדרי משאבות, מערכות הגברת לחץ, ניקוז וביוב.
הדוחות נוצרים כמכתב רשמי ונשמרים כ-PDF. כל עובד נכנס עם משתמש משלו וחותם על הדוחות שלו.

- **אתר:** Netlify, מתעדכן אוטומטית מהמאגר הזה
- **נתונים וכניסה:** Firebase (Authentication + Firestore)
- **התקנה בטלפון:** אפשר להתקין את האתר כאפליקציה (PWA)
